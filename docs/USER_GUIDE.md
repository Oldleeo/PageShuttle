# 使用教程

## 导入节点

点击“导入”，可选择：

- 粘贴 Clash YAML、Base64 订阅文本或多个节点链接；
- 填写 HTTP/HTTPS 订阅地址；
- 选择本地 `.yaml`、`.yml`、`.txt` 或 `.conf` 文件。

支持 `vless://`、`vmess://`、`trojan://`、`ss://`、`http://`、`https://`、`socks4://` 和 `socks5://`。

## 搜索和收藏

- 搜索框可按节点名称、服务器、协议、传输方式和收藏分组过滤；
- 点击星标把节点加入收藏；
- 点击“收藏分组”新建、查看或删除分组。

## 启动与暂停

选中节点后点击顶部“启动”。页梭只修改当前 Chrome 用户配置的代理；点击“暂停”会清除 Chrome 代理并停止页梭自己的 Xray。它不会关闭 v2rayN 或其他代理软件，也不会修改 Windows 或 macOS 系统代理。

## 浏览器环境

- 自动：根据代理出口 IP 同步网页可见定位、国家语言和时区；
- 手动：输入经纬度、两位国家代码、locale 和 IANA 时区；
- 关闭：只使用代理，不覆盖网页环境。

语言开关只改变网站通过 JavaScript 读取到的 locale，不修改 Chrome 菜单和页梭中文界面。字体保护不会改变网页实际显示字体。

## 指定网站代理

在设置中把“代理范围”改为“仅指定网站走代理”，每行填写一个域名，例如：

```text
google.com
*.openai.com
```

IP 检测服务始终通过当前代理访问，以便确认出口位置。

## 更新

页梭每 12 小时自动检查一次公开 GitHub Release，但不会未经确认安装。也可以在设置底部手动点击“检查更新”。
